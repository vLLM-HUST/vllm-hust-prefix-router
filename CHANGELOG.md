# Changelog

## 0.1.0a1

- Promote the external Router carrier to active Manifest 0.3 intent with a
  dedicated Extension Manager provider.
- Bind declared backend and KV-event services to the running Router config,
  process identity, event recovery, and backend health before managed launch.
- Add GitHub OIDC publication workflow for the `intellistream` PyPI organization
  with CPython-specific bytecode wheels and no source distribution.

## 0.1.0.dev0

- Create an inert, discoverable external control-plane extension package.
- Extract the cleaned request-lifecycle block accounting core.
- Extract a framework-neutral Prefix cache index.
- Add isolated per-backend HTTP connection pools with bounded queueing.
- Keep the extension manifest `import_only` until end-to-end acceptance.
